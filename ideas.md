# Design brief

## Direction: Instrument Panel for Evidence
A restrained research-instrument interface: a cool paper-like canvas, deep navy navigation rail, and crisp status colors for retrieval signals. Probability: 0.08.

## Design dimensions
- **Movement:** editorial lab dashboard; dense but calm, with information arranged as inspectable modules.
- **Principles:** evidence is visible, not implied; show metrics before prose; selection decisions should feel auditable.
- **Color philosophy:** navy for system context, cobalt for action and relevance, violet for information gain, amber for caution, green for sufficiency.
- **Layout:** persistent navigation, generous page header, metric cards, two-column analytical panels, responsive collapse on narrow screens.
- **Signature elements:** network mark, monospace eyebrows, candidate meters, source decision traces, and small status chips.
- **Interaction:** direct and reversible; clicking a sample question opens the ask workspace, source rows expand in place, rejected evidence is visually distinct.
- **Animation:** subtle hover lift, spinner only while retrieval is running, no decorative motion.
- **Typography:** Space Grotesk for headings, DM Sans for interface copy, DM Mono for labels and numeric signals.
- **Brand essence:** grounded, transparent, research-grade.
- **Brand voice:** concise, specific, honest about what is measured versus illustrative.
- **Wordmark:** EVIDENCE/RAG, paired with a geometric branching-network mark.
- **Signature brand color:** cobalt #3975F6.
